## GazeBaseVR

Dillon James Lohr, Samantha Aziz, Lee Friedman, and Oleg V. Komogortsev. *GazeBaseVR, a large-scale, longitudinal, binocular eye-tracking dataset collected in virtual reality*. Scientific Data 10, 177 (2023). [Source article](https://doi.org/10.1038/s41597-023-02075-5). [Official data repository](https://figshare.com/articles/dataset/GazeBaseVR_Data_Repository/21308391).

The primary study uses round-1 250 Hz SMI/HTC Vive recordings and the associated public questionnaire metadata. It uses selected later returning subsets for descriptive context. Dataset-level availability should not be read as a claim that every source recording contributes to every result.

## GazeBase

Henry Griffith, Dillon James Lohr, Evgeny Abdulin, and Oleg V. Komogortsev. *GazeBase, a large-scale, multi-stimulus, longitudinal eye movement dataset*. Scientific Data 8, 184 (2021). [Source article](https://doi.org/10.1038/s41597-021-00959-y). [Official data repository](https://figshare.com/articles/dataset/GazeBase_Data_Repository/12912257).

The supplementary sampling/injection check uses selected 1000 Hz EyeLink RAN recordings. It does not calibrate the HMD or identify the true physiological session effect.

## Distribution routes

Download the archives directly from the official version DOIs above. A secondary mirror is available as 18 split assets in the [raw-data-v1 Release](https://github.com/moumoubin99/vr-fatigue-measurement-audit/releases/tag/raw-data-v1), with an attached binary manifest; see `DOWNLOAD_AND_REASSEMBLE.md`. The complete local archives matched the original bytes and MD5 values above before splitting. Part bytes and SHA-256 digests matched GitHub server metadata. The ordered records are in `release-manifests/raw-data-v1.json` and the attached `raw-data-v1.manifest.json`. No original archive is stored in Git history.

The source-dataset DOIs above identify upstream data. No DOI for this code release or the associated manuscript has been assigned in this package.
